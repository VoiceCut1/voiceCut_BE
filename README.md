## Noah: Troubleshooting

### 1. 동기 작업과 비동기 작업이 공존할 때, Redis의 트랜잭션이 필요할까?

결론적으로 트랜잭션이 필요 없다고 판단했다.
Redis는 트랜잭션을 설정하지 않아도 단일 명령은 항상 원자적으로 수행한다. 즉, 원자성을 보장할 수 있다.
다만 Redis가 아닌 자바에서 직렬화/역직렬화 및 레디스 연결 문제가 발생할 수 있으므로 전체 작업을 원자적으로 처리하려면 트랜잭션을 설정하는 것이 좋다.
현 프로젝트에서 직렬화/역직렬화, 레디스 연결 문제는 고려 대상이 아니기 때문에 트랜잭션을 사용하지 않을 예정이다.
