# 전화대장군 Backend

2024년 제6회 K-디지털 트레이닝 해커톤 - 팀 음성감독원

## 프로젝트 소개

노년층 보이스피싱 피해 방지를 위한 AI 기반 실시간 통화 분석 서비스

## 주요 기능

- 실시간 음성 데이터 수신 및 STT 변환 (OpenAI Whisper)
- AI 기반 보이스피싱 위험도 분석 (0~100점)
- FCM 푸시 알림 (사용자 및 보호자)
- SMS 경고 메시지 발송

## 기술 스택

- Java 17, Spring Boot
- Redis
- OpenAI Whisper API, GPT API
- Firebase Cloud Messaging
